## 概述

词频分析是 TrendRadar 的核心功能之一，用于从海量新闻中筛选出你关心的内容。系统会：

1. **读取配置**：从 `config/frequency_words.txt` 加载关键词配置
2. **匹配新闻**：遍历所有新闻标题，匹配关键词规则
3. **统计词频**：统计每个关键词组匹配到的新闻数量
4. **计算权重**：根据排名、频次、热度计算新闻权重
5. **排序输出**：按权重和配置位置排序，生成报告

## 配置文件语法

配置文件位置：`config/frequency_words.txt`

### 基本结构

配置文件使用**空行分隔**不同的关键词组，每个词组代表一个监控主题。

```
关键词1
关键词2
关键词3

另一个主题的关键词1
另一个主题的关键词2
```

### 五种语法类型

#### 1. 普通词（基础匹配）

**语法**：直接写关键词，无需前缀

**作用**：标题包含任意一个普通词即匹配

**示例**：
```
苹果
iPhone
iOS
```

**匹配规则**：
- ✅ "苹果发布新iPhone" → 匹配（包含"苹果"）
- ✅ "iOS 18 新功能" → 匹配（包含"iOS"）
- ❌ "安卓系统更新" → 不匹配

---

#### 2. 必须词（+ 前缀）

**语法**：在关键词前加 `+` 号

**作用**：标题必须同时包含所有必须词才匹配

**示例**：
```
比特币
以太坊
+突破
```

**匹配规则**：
- ✅ "比特币突破5万美元" → 匹配（包含"比特币"和"突破"）
- ✅ "以太坊突破3000美元" → 匹配（包含"以太坊"和"突破"）
- ❌ "比特币价格下跌" → 不匹配（缺少"突破"）
- ❌ "突破技术分析" → 不匹配（缺少"比特币"或"以太坊"）

**注意**：必须词会与普通词组合使用，标题需要：
- 包含任意一个普通词（"比特币"或"以太坊"）
- **并且**包含所有必须词（"突破"）

---

#### 3. 过滤词（! 前缀）

**语法**：在关键词前加 `!` 号

**作用**：标题包含过滤词则排除，不匹配

**示例**：
```
ai
人工智能
!gai
```

**匹配规则**：
- ✅ "AI 技术突破" → 匹配（包含"ai"，不包含"gai"）
- ✅ "人工智能发展" → 匹配（包含"人工智能"，不包含"gai"）
- ❌ "GAI 音乐生成" → 不匹配（包含过滤词"gai"）

**注意**：过滤词是**全局生效**的，会应用到所有词组

---

#### 4. 数量限制（@ 前缀）

**语法**：`@数字`，如 `@10`

**作用**：限制该关键词组最多显示的新闻数量

**示例**：
```
特斯拉
马斯克
@5
```

**效果**：即使匹配到10条新闻，也只显示权重最高的5条

**优先级**：
- 词组内配置（`@5`） > 全局配置（`config.yaml` 中的 `max_news_per_keyword`）

---

#### 5. 全局过滤（[GLOBAL_FILTER] 区域）

**语法**：使用区域标记 `[GLOBAL_FILTER]`

**作用**：全局排除包含这些词的新闻，优先级最高

**示例**：
```
[GLOBAL_FILTER]
广告
推广
震惊
标题党

[WORD_GROUPS]
苹果
iPhone
```

**匹配规则**：
- ❌ "苹果广告投放" → 不匹配（包含全局过滤词"广告"）
- ❌ "震惊！iPhone 新功能" → 不匹配（包含全局过滤词"震惊"）
- ✅ "苹果发布新iPhone" → 匹配

**优先级**：全局过滤 > 词组内过滤词 > 必须词 > 普通词

## 匹配逻辑

### 匹配流程

```
新闻标题
    ↓
1. 全局过滤检查（优先级最高）
    ├─ 包含全局过滤词？ → ❌ 排除
    └─ 不包含？ → 继续
    ↓
2. 检查是否有词组配置
    ├─ 无配置？ → ✅ 匹配所有（显示全部新闻）
    └─ 有配置？ → 继续
    ↓
3. 过滤词检查
    ├─ 包含过滤词？ → ❌ 排除
    └─ 不包含？ → 继续
    ↓
4. 遍历所有词组
    ├─ 检查必须词（+）
    │   ├─ 缺少任意必须词？ → 跳过该词组
    │   └─ 包含所有必须词？ → 继续
    │
    └─ 检查普通词
        ├─ 包含任意普通词？ → ✅ 匹配该词组
        └─ 不包含？ → 跳过该词组
    ↓
5. 匹配成功 → 统计到对应词组
```

### 代码实现

```python
def matches_word_groups(
    title: str, 
    word_groups: List[Dict], 
    filter_words: List[str], 
    global_filters: Optional[List[str]] = None
) -> bool:
    """检查标题是否匹配词组规则"""
    
    title_lower = title.lower()
    
    # 1. 全局过滤检查（优先级最高）
    if global_filters:
        if any(global_word.lower() in title_lower for global_word in global_filters):
            return False  # 包含全局过滤词，直接排除
    
    # 2. 如果没有配置词组，匹配所有
    if not word_groups:
        return True
    
    # 3. 过滤词检查
    if any(filter_word.lower() in title_lower for filter_word in filter_words):
        return False  # 包含过滤词，排除
    
    # 4. 词组匹配检查
    for group in word_groups:
        required_words = group["required"]  # 必须词（+前缀）
        normal_words = group["normal"]       # 普通词
        
        # 必须词检查：必须全部包含
        if required_words:
            all_required_present = all(
                req_word.lower() in title_lower 
                for req_word in required_words
            )
            if not all_required_present:
                continue  # 缺少必须词，跳过该词组
        
        # 普通词检查：包含任意一个即可
        if normal_words:
            any_normal_present = any(
                normal_word.lower() in title_lower 
                for normal_word in normal_words
            )
            if not any_normal_present:
                continue  # 不包含普通词，跳过该词组
        
        return True  # 匹配成功
    
    return False  # 所有词组都不匹配
```

### 排序规则

#### 词组排序

**默认**：先按匹配数量（降序），再按配置位置（升序）

```python
stats.sort(key=lambda x: (-x["count"], x["position"]))
```

**配置选项**：`sort_by_position_first: true` 时，先按配置位置排序

```python
stats.sort(key=lambda x: (x["position"], -x["count"]))
```

#### 新闻排序

每条新闻按以下优先级排序：

1. **权重**（降序）- 最重要
2. **最小排名**（升序）- 排名越靠前越好
3. **出现次数**（降序）- 出现越多次越重要

## 权重计算

### 权重公式

```python
def calculate_news_weight(title_data: Dict, rank_threshold: int = 5) -> float:
    """计算新闻权重"""
    
    ranks = title_data.get("ranks", [])  # 如：[1, 3, 5]
    count = title_data.get("count", len(ranks))  # 出现次数：3
    
    # 1. 排名权重（60%）
    # 公式：Σ(11 - min(rank, 10)) / 出现次数
    rank_scores = []
    for rank in ranks:
        score = 11 - min(rank, 10)  # 排名1得10分，排名10得1分
        rank_scores.append(score)
    rank_weight = sum(rank_scores) / len(ranks)  # 平均分
    
    # 2. 频次权重（30%）
    # 公式：min(出现次数, 10) × 10
    frequency_weight = min(count, 10) * 10  # 最多100分
    
    # 3. 热度权重（10%）
    # 公式：高排名次数 / 总出现次数 × 100
    high_rank_count = sum(1 for rank in ranks if rank <= rank_threshold)
    hotness_ratio = high_rank_count / len(ranks)
    hotness_weight = hotness_ratio * 100
    
    # 4. 加权求和
    total_weight = (
        rank_weight * 0.6 +      # 排名权重 60%
        frequency_weight * 0.3 +   # 频次权重 30%
        hotness_weight * 0.1       # 热度权重 10%
    )
    
    return total_weight
```

### 权重配置

在 `config/config.yaml` 中可配置权重比例：

```yaml
weight:
  rank_weight: 0.6      # 排名权重 60%
  frequency_weight: 0.3  # 频次权重 30%
  hotness_weight: 0.1    # 热度权重 10%
```

### 权重计算示例

**示例1：高排名、高频次**
- 排名：[1, 2, 3]
- 出现次数：3
- 排名权重：(10+9+8)/3 = 9.0
- 频次权重：min(3,10)×10 = 30
- 热度权重：3/3×100 = 100
- **总权重**：9.0×0.6 + 30×0.3 + 100×0.1 = **18.4**

**示例2：低排名、低频次**
- 排名：[15, 20, 25]
- 出现次数：3
- 排名权重：(1+1+1)/3 = 1.0
- 频次权重：min(3,10)×10 = 30
- 热度权重：0/3×100 = 0
- **总权重**：1.0×0.6 + 30×0.3 + 0×0.1 = **9.6**

## 总结

词频分析功能通过**灵活的配置语法**和**智能的匹配逻辑**，帮助你：

1. **精准筛选**：只关注你关心的主题
2. **排除干扰**：过滤掉广告、推广等无关内容
3. **智能排序**：按权重自动排序，重要新闻优先
4. **数量控制**：限制显示数量，避免信息过载

通过合理配置关键词，你可以构建一个**个性化的新闻监控系统**，只接收真正有价值的信息。
